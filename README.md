# 数学の発想ノート

数学の問題と自分の答案を保存し、後日見返して再挑戦するための落ち着いた学習用Webアプリです。

## 主な特徴

- **どの機種からログインしても同じ情報を閲覧可能（Supabase連携）**
  - PC・Chromebook・スマホから同じアカウントでログインすると、問題・答案画像・振り返りメモを同期して閲覧できます。
  - Supabase未設定の状態でも、ローカル保存モード（ブラウザ内保存）としてすぐにお試しいただけます。
- **問題一覧**：教材名・問題番号・単元・復習状態（未着手／確認中／復習済み）・画像有無を一覧表示し、開く前に答案やメモが見えない構成です。
- **登録・編集**：問題画像と答案画像を分けて複数枚添付でき、サムネイル確認や離脱時の確認ダイアログ、保存状態の明確な表示に対応しています。
- **詳細・復習**：「通常閲覧」と「再挑戦（解答・メモを隠す）」を切り替えられ、PCでは問題と答案の並列表示、スマホでは縦並び、画像クリックで拡大表示に対応しています。

## 複数端末で同期するための設定手順（Supabase）

1. [Supabase](https://supabase.com/) で無料プロジェクトを作成します。
2. SQL Editor で `supabase_schema.sql` の内容を実行します（`problems` テーブルと非公開画像バケット `math-review-images`、本人のみアクセス可能なRLSポリシーが作成されます）。
3. Project Settings → API から **Project URL** と **anon public key** を控えます。
4. `config.js` の `DEFAULT_CONFIG` に直接記入してGitHub Pages等へ公開するか、アプリ内の「データ・設定」画面から入力して保存します。
